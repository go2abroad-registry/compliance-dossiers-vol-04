法定设立与首期章程 (Statutory Formation)

主管官方机构、法典依据、验资锁资规程与首期董事会决议范本。

官方主管注册局

注册办事处所在州的商业注册办公室（Handelsregisteramt），受联邦司法办公室监督；通过e-GR/PrivaSphere门户及Zefix全国商业名称索引进行电子申报。

现行法典依据

《瑞士义务法》（Obligationenrecht / Code des obligations），第五部分：商业登记与商业公司，第620-763条涉及股份公司（Aktiengesellschaft）的相关规定；特别是第626条（公司章程的必备内容）、第630条（商业登记申请）、第630a条（董事资格声明）、第631条（实收资本要求）、第640条（审计豁免）以及第950条（商业登记信息系统）；此外还有《瑞士商业登记条例》（Handelsregisterverordnung, HregV）。

法定设立章程文件

经公证的设立文件（Gruendungsurkunde / 设立证书）与公司章程（Statuten）一同作为法定登记文件提交至商业登记处，并随后在瑞士商业官方公报（SOGC）上公布。

法定实缴资本与验资锁资账户流程 免验资锁资账户

标准AG公司注册要求最低名义股本为100,000瑞士法郎（根据第621条规则）；在注册前，至少需支付20%的名义金额，且必须至少有50,000瑞士法郎以现金形式缴纳；已缴纳的部分必须存入FINMA许可的瑞士银行中的冻结资本账户中，并需有书面银行资本确认文件作为证明；实物出资则需经持牌审计师确认；未支付的余额可由董事会随时调用。

注资与解冻路径: 注册地址必须持有有效的建筑火灾保险证明；如果采用货架或储存系统，则还需要有结构荷载证书，以及根据 VKF / NVK 规定由州消防部门进行的消防安全检查。为了保障职业安全，需遵守SUVA和SECO劳动法规定：公司必须根据瑞士事故预防条例完成风险评估，配备急救设备，为员工购买强制性的事故保险，并将工作场所的相关说明记录在企业档案中。

进入瑞士增值税征税范围的外国实体，必须通过SuisseTax注册门户或表格9.2向瑞士税务管理局（ESTV）申请瑞士增值税号码（MWST-Nr./UID CHE），方可开始应税供应。非瑞士设立的商业实体可直接申请；瑞士分支机构及股份公司则在完成商业登记后，通过瑞士中央企业名称索引（Zefix）获取商业识别号码，该号码将自动导入ESTV。

跨境出口 0% 零税率申报条件

对于所有权转移给外国买家，且货物实际交付或运出瑞士的商品出口行为，可享受零税率待遇；这可通过海关申报证明。瑞士增值税法第23条第2款中规定的某些服务以及与出口商品直接相关的辅助服务也符合零税率的条件。只有商品能够交付给外国或最终客户，且商品确实从瑞士出口的，才符合零库存销售的交易条件。

  • 海关出口申报（瑞士纳尔瓦或Tradenet申报，或官方边境海关办公室放行）
  • 提单/空运单/证明从瑞士出境的托运运输单据，

外汇管制与央行政策诊断

经常项目兑换自由度

瑞士完全遵循国际货币基金组织第八条的规定，允许瑞士法郎在货币交易和资本账户交易中实现完全无限制的兑换。没有外汇管制法规，也没有对跨境支付的要求需经中央银行批准；对利润分配、股息汇出或投资资本的回流也没有任何限制。唯一的强制性义务是：(i) 根据《反洗钱法》，FINMA需履行反洗钱识别和报告职责；(ii) 针对金融中介机构的统计报告要求。公司向股东汇发利润时，需要经过正式的股东决议，确认符合《瑞士义务法典》第660条和第671条的规定，并且除非利润分配属于对出资金的偿还，否则需要在来源地缴纳35%的瑞士预扣税；无需进行外汇管制审批。

出口外汇强制结汇要求

根据瑞士法律，没有关于出口收入上缴或遣返的法定时间限制。强制兑换比例为零：以外币获得的出口收入可以无限期地保留在国内或国外银行账户中，无需经SNB或FINMA批准。唯一相关的义务包括商业记账和税务申报责任（《民法典》第957条及后续条款；《增值税法》第58条），包括按照瑞士GAAP（FER）或IFRS标准对外币应收款项进行资产负债表确认和头寸估值；增值税处理则遵循《增值税法》第23条的规定，无需在海关进行外汇兑换。
