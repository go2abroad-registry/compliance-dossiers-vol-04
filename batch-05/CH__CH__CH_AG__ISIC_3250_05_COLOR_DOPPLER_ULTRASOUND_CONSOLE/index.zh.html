瑞士的企业所得税在联邦、州和市镇各级都需缴纳，对于股份公司而言则没有可以选择的税务分类选项。股份公司属于独立的纳税主体，其全球收入需缴纳企业所得税，除非有条约或国内法规另有规定。根据瑞士国内的反滥用规定以及OECD BEPS最低标准，混合分类选项受到限制；根据瑞士税法，瑞士居民股份公司无法选择特定的税务分类方式。

强制登记营业额门槛 (Nexus)

除非供应品 exclusively 与出口相关或为跨境供应，否则年全球 taxable 供应额为10万瑞郎；在供应品为跨境或境外对境外供应的情况下，可自愿注册；对于非居民供应商，自首次在瑞士产生应税供应之日起，无论营业额是否达到门槛，均须强制注册。

跨境出口 0% 零税率申报条件

从瑞士向非瑞士领土出口有形货物，若卖方能够证明货物已离开瑞士海关领土并进入境外目的地，则可享受0%增值税。若服务实际在境外使用并享受，且接收方位于瑞士境外，且收益在境外实现，则该服务可享受零税率或不征收瑞士增值税。供应商须保留可靠的商业证据以证明境外供应，包括合同、运输单据及海关确认文件。

  • 海关出口申报（Zollanmeldung）
  • 商业发票/报价单
  • 运输证明（CMR/空运提单/提单）
  • 银行或付款证明（入账汇款凭证/SWIFT MT103）
  • 外国收款人及税务状况证明（例如：外国增值税注册证明或居留证）

目前瑞士并不实施强制性的实时财务清算或持续交易控制机制。不过，电子发票支付是被认可的，而瑞士QR票据标准则成为企业发票出示的强制要求。虽然没有强制性的电子发票清算API，但所有发票都必须符合瑞士增值税发票的要求（如增值税号码、开具方、接收方、供应类型、税率和金额等）。FTA正在逐步推行数字交换机制，但目前并未实施预清算盖章制度。

FTA可以通过文件审计来严格审查出口零税率的情况。如果虚假申请了零税率，那么增值税就需要缴纳，利息也会开始计算，还可能被处以高达逃税增值税100%的罚款（增值税法第96条）。在严重情况下，还可能面临税务逃避处罚和刑事没收措施。对于增值税评估期而言，追溯扣回通常仅限于十年时间；此外，任何虚假记录的出口申报行为都可能引发瑞士海关和增值税法规下的处罚程序。

经常项目兑换自由度

瑞士法郎完全具有可兑换性，瑞士也不实施任何外汇管制。当前账户和资本账户交易都得到了充分自由化；瑞士外汇管制法律不要求事先许可、不设定许可证制度、不要求对账户进行限制，也不对利润汇出或股息汇回施加任何限制。唯一存在的障碍包括对股息和债务报酬所征收的瑞士预扣税、公司间支付所需的转移定价文件，以及银行进行的审慎的反洗钱/了解客户检查。输入和输出支付可以通过任何受FINMA监管的银行自由进行，但必须遵守瑞士制裁法律和瑞士刑法中的反洗钱规定。

出口外汇强制结汇要求

瑞士不要求出口收益必须上交，也不规定强制兑换比例或持有期限要求。出口商可以保留以任何自由兑换货币表示的发票和收款凭证，可以在瑞士银行设立以外币计价的营运资金账户，并且可以在无需中央银行批准的情况下重新组合结算收益。瑞士银行仅根据瑞士支付交易统计框架向瑞士国家银行进行跨境支付的统计报告；不存在公司层面的报告或汇回义务。

央行监管: 瑞士国家银行（Schweizerische Nationalbank / Banque nationale suisse / Banca nazionale svizzera）；没有独立的外汇管理部门；其职责包括瑞士货币政策和国际收支统计报告，而国际金融事务国务秘书处与SECO则负责制裁和金融市场相关事务。

离岸数字新锐银行 / EMI 白名单

Cross-border EMI / Fintech rails 适配度: High

可行性评级：辅助性支付流程方面为中等水平，核心资金管理及贸易结算功能方面则为低水平。获得FINMA许可的瑞士金融科技公司和数字银行可为瑞士州属公司（CH-AG）开设瑞郎及外币收款账户，接收SIC付款，并提供在线外汇兑换服务；然而，它们通常不提供商业信用证服务、SWIFT MT700报文的开具，或托管/资本冻结账户服务。来自欧盟经济区（EEA）或英国的海外金融机构无法实现“互认”进入瑞士市场，必须获得瑞士FINMA的许可或通过本地持牌代理方可合法接入瑞士实体。因此，仅提供海外金融机构服务的离岸结构，无法作为一级企业银行关系的合规替代方案。

转让定价与经济实质

主文档/本地文档门槛: 尽管瑞士法律并未像其他OECD国家那样明确规定一个完全的本地文件提交门槛，但瑞士税务局（ESTV）及主要州级税务主管部门均要求，一旦跨境关联交易在任何特定年度超过300万瑞士法郎，即应提交完整的劳动与实质文件；当交易金额具有重大性，且纳税人申请税收协定优惠或请求相互协商程序时，必须提交完整的本地文件。

经济实质审查范围: 瑞士不实施阿联酋式的“经济实体”规定，但在“15%限制”和OECD第二支柱规则下，声称享有条约优惠或拥有特殊权利的AG必须切实在瑞士拥有实际员工、实际存在、决策能力以及正常运作的医疗器械贸易业务；没有运营活动的虚假进入交易将被重新视为纯粹的被动财富保存手段，从而无法获得条约优惠及部分参与扣除。

致命合规红线与董事个人责任

逃税 / 低估跨境销售收入

法定制裁: 罚款最高可达逃避税款金额的三倍并加收利息；各州税务机关可处以重大程序性罚款；在情节特别严重的情况下，将逃税行为公布于州官方公报。

董事个人责任: 明知签署虚假税务申报的董事，须就逃避的全部税款承担个人责任，将面临刑事罚款，并在严重税务欺诈案件中可能被实施旅行禁令，最高可被判处五年监禁。
空壳公司 / 缺乏实质运营

法定制裁: 瑞士税务机构将依据“透明公司原则”揭开公司的面纱，将所有收入分配给外国实益所有人，从而对联邦和州层面的企业所得税、预扣税及增值税进行追溯征收，并可能处以逃税金额三倍的罚款；该企业的商业登记状态也可能被暂停。

董事个人责任: 空壳公司的董事会成员可以个人承担未缴预提税的偿还责任（在极端情况下可高达100万瑞士法郎），而登记机构若在外国董事使用瑞士公司形式只是为了逃避外国税收，可能会对其旅行进行限制。
反洗钱/制裁/出口管制合规违规

法定制裁: 根据瑞士洗钱法，企业可能面临最高50万瑞士法郎的罚款，此外还可能包括资产没收、商业登记资格取消以及监管禁止措施；根据禁运法，违反出口管制规定则可能被处以1至5年的监禁和高额罚款。

董事个人责任: 任何明知而故意隐瞒最终受益所有人身份或指令交易的个人董事或高级管理人员，将承担刑事责任，可能被处以罚款和监禁，且该董事不能以公司有限责任为由获得豁免。
错误/虚假的转让定价文档

法定制裁: 虚假或欺诈性的TP文件将导致瑞士税法体系重新采用独立交易原则；纳税人将丧失“谨慎纳税人”豁免权，并面临最高达3万瑞郎的程序性罚款，以及附加公司税和逾期利息；在欺诈性案件处理程序中，税务机关可对纳税人处以隐藏额外税额30%至150%的刑事罚款。

董事个人责任: 如果公司无法支付罚款，负责制作虚假TP文件的法定代表人或业务主管将需共同承担刑事责任，并可能被禁止在五年内担任任何瑞士公司的董事。
延迟股息分配 / 未代扣代缴预提税

法定制裁: 瑞士股份公司需从其自有资金中支付全额35%的预提税，以及4.5%的逾期利息和延期罚金；持续未缴税款将构成对遗产的债权，可加速破产程序。

董事个人责任: 未为扣缴税款预留资金而发出股息指令的董事，将与税务机关共同承担未缴扣缴税款的责任，且在屡次发生的情况下，可能因未获覆盖的擅自处置行为而面临刑事起诉。
