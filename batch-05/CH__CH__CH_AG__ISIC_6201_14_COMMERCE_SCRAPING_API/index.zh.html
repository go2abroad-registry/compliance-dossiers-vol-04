电子政务申报门户

外国实体须使用SFTA表格754（增值税登记表）申请瑞士增值税号码（MWST-Nummer）。如果该实体不位于瑞士境内，但在瑞士境内从事应税活动，则必须指定一名瑞士境内税务代表或财政机构。申请时需提交商业注册簿摘录、章程、董事会决议以及预计营业额的证明文件。注册成功后，该实体将获得瑞士企业识别号码（Unternehmens-Identifikationsnummer），该号码也作为其所有瑞士税种的税号使用。对于未在瑞士商业注册簿中注册的实体，将另行分配一个独立的增值税号码。

瑞士法律并不提供“勾选选项”式的选择方式。股份有限公司在联邦、州和市镇的企业所得税方面自动成为独立的纳税实体，并且还需缴纳瑞士预提税。关于增值税，根据《瑞士增值税法》第21条，可以选择进行集团化征税。混合模式下的选择并不被认可；瑞士仅在实际实施的范围内适用与OECD BEPS行动2相一致的国内反混合规则。

强制登记营业额门槛 (Nexus)

年全球营业额达到10万瑞士法郎（增值税法第10条第2款）的国内经营者；对于外国经营者，当来源于瑞士的应税营业额超过每年10万瑞士法郎且该外国业务尚未享受免税待遇时，须进行登记；对于营业额较小的情况，可自愿登记。非营利性体育和慈善活动适用特别降低的门槛，为2.5万瑞士法郎。

跨境出口 0% 零税率申报条件

根据第18条和第19条，零费率（0%）《瑞士增值税法》适用于：(1) 从瑞士出口到外国的动产商品，前提是这些商品由供应商、买方或第三方实际运出瑞士；(2) 服务交易，即接收方位于国外且该服务在国外实际使用。对于不动产、商品相关服务以及客运业务则有限度地予以排除；(3) 与出口商品直接相关的运输服务及其他服务。对于模糊不清的案件，可以提前作出裁决；但在交付后60天内，零利率必须提供书面证据加以证明，不过也可以予以延期。

瑞士并不强制实施实时财务结算系统（没有类似CFDI/PEPPOL的结算要求）。不过，根据瑞士增值税法，通过电子方式开具发票时，为了便于审计追踪，必须使用瑞士QR账单格式（ISO 20022）进行电子开票。对于企业向政府进行的交易，自2020年起，联邦采购领域也要求必须采用电子开票方式。SFTA并不要求使用基于API的财务盖章机制；相反，纳税人需保留原始电子记录，并在接到请求时提供这些记录。

瑞士税务机构对欺诈性出口零税率申请实施严格的追溯措施。如果SFTA认定出口文件被伪造或货物并未离开瑞士，那么零税率将被追溯取消，同时需按标准税率（8.1%）缴纳增值税及利息。此外，还可能面临最高为逃税金额三倍的额外罚款（《增值税法》第70-74条）；根据《瑞士联邦行政刑事法》第186-187条，针对税收欺诈行为可提起刑事起诉，个人可能面临高达10万瑞士法郎的罚款或监禁。对于欺诈性申请，起诉的时效为15年；而对于故意隐匿行为，普通评估的时效则为10年。

外汇管制与央行政策诊断

经常项目兑换自由度

瑞士拥有完全的资本和经常账户可兑换性。瑞士法郎是一种可以自由兑换的全球储备货币，不存在外汇管制。外国投资者可以根据瑞士的企业和税收法律，自由地投入资金、汇回本国以及汇出利润。从货币角度来看，利润汇出的障碍基本不存在；不过，对于股息分配，需要缴纳35%的瑞士预提税，但在符合相关双重征税协定的情况下，这一税率可以降低。对于持有公司资本不足5%的外国投资者来说，出售股份所得的利润通常无需纳税；而公司之间的贷款则必须遵循薄资本化原则、公平利率标准以及实质要求，以避免被认定为隐藏的股权分配。

出口外汇强制结汇要求

瑞士不对出口收入实施任何法定上交或强制兑换规定。出口商可以自由保留、使用或转换为任何货币，也没有规定的回国时间限制。唯一的相关义务包括以瑞士法郎或功能货币进行商业记账和税务申报，以及根据《反洗钱法》对大型或可疑跨境交易进行透明度和反洗钱申报要求。

央行监管: 瑞士国家银行（SNB）与联邦财政部门及国际金融事务国务秘书处（SIF）共同负责相关事务；瑞士不存在专门的外汇管理机构。

离岸数字新锐银行 / EMI 白名单

Cross-border EMI / Fintech rails 适配度: High

跨境电子货币业务的可行性较低至中等。若涉及存款业务和支付中介服务，必须取得瑞士许可证，例如瑞士金融市场监管局（FINMA）颁发的“金融科技”或“银行创新者”许可证，或完整的银行牌照。境外数字电子货币机构（如英国、立陶宛或新加坡的电子货币机构）不具有瑞士的“护照权”，无法直接向瑞士提供受监管的账户开立或支付收款服务。此类机构仅可作为未经监管的支付“出账”服务提供商，需附加合同免责条款，并遵守瑞士反洗钱法规；在实际操作中，瑞士股份公司应仅与FINMA监管的支付机构或持牌银行合作，以确保资金管理的信誉，并避免引发反洗钱警示。
