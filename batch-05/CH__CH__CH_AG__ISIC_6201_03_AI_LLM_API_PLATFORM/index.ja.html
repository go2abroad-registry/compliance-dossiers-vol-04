為替管理の自由度 スイスでは、資本取引と現金取引を区別することなく、完全に自由化された変換可能通貨制度が運用されている。非居住者はスイスフランを自由に保有し、配当金や利益、ロイヤルティ、資本を任意の変換可能通貨で送金することができる。利益の送金や資本の返還には事前の承認は必要なく、ただしスイス銀行に課される標準的なマネーロンダリング対策の書類要件のみが必要である。スイスフランには為替管理制限はなく、外国通貨口座にも制限はない。しかし、SNBは特別な状況下で一時的な保護措置を講じる法的権限を持っており、その中には負の金利や義務的準備金要求などが含まれる。ただし、これらの措置は歴史的に国内の流動性を対象としてきたものであり、国境を越えた変換可能性とは関係ない。

Export 0% zero-rating conditions

商品がスイスから物理的に輸出され、輸出の証明書が提出された場合、輸出に係る消費税は0%と認められる。AI LLM APIプラットフォームにおいて、海外のビジネス顧客へのデジタル・データベースサービスの離島供給は、供給場所の規則に基づきスイス消費税の適用範囲外とされ、受取人はスイス以外の事業者であり、外国の事業所の文書的証明が保持されている場合、ゼロレートが適用される。しかし、スイスの個人消費者へのサービスは、輸出ゼロレートの対象とならない。

  • 関税輸出申告（オーストラリア輸出証 / スイス関税e-decプロセスによる申告）
  • 輸送証明書または航空運送証明書（国際輸送証明）
  • 送金証明書または外国銀行の貸付明細書（支払い証明）

スイスでは、リアルタイムの財政処理や印鑑付け、または政府のAPIによる請求書の承認は行われません。スイスのQR請求書の要件が支払い文書を規定しています。VAT適用はESTVの安全な電子サービスポータルを通じて提出される定期報告書によって行われ、電子記録が受け入れられますが、継続的な取引管理の要件はありません。

ESTVは、輸出申告、国際輸送書類、契約、支払い証拠を照合することにより、零税率の請求を検証する。根拠のないまたは虚偽の零税率は、再評価および遅延金、行政罰により取り消される。意図的な消費税の逃税は、刑事罰および懲役を含み、逃税に関する過去の再評価については10年間の期間が適用される。通常の評価期間は5年である。スイスの外貨帰還に関する法的期間は設けられていないが、輸出の証拠確認における支払いの調整において、行政的に180日を基準として適用する。

Foreign Exchange Regime & Central Bank Policy

Current-account convertibility

スイスでは、資本取引と現金取引を区別することなく、完全に自由化された変換可能通貨制度が運用されている。非居住者はスイスフランを自由に保有し、配当金や利益、ロイヤルティ、資本を任意の変換可能通貨で送金することができる。利益の送金や資本の返還には事前の承認は必要なく、ただしスイス銀行に課される標準的なマネーロンダリング対策の書類要件のみが必要である。スイスフランには為替管理制限はなく、外国通貨口座にも制限はない。しかし、SNBは特別な状況下で一時的な保護措置を講じる法的権限を持っており、その中には負の金利や義務的準備金要求などが含まれる。ただし、これらの措置は歴史的に国内の流動性を対象としてきたものであり、国境を越えた変換可能性とは関係ない。

Export proceeds surrender rules

スイスは、輸出収入の引き渡しや送還に関して法定な期限を定めておらず、スイスフランへの強制的な換算比率もありません。AI APIプラットフォームを含む輸出業者やデジタルサービスプロバイダーは、外貨受取金をオープンな銀行間市場で保持したり、再投資したり、またはスイスフランに換算することが自由です。しかし、銀行の顧客は、輸出収入をスイス銀行口座で処理する際に経済的背景や資金の出所を明確にするため、スイスの義務法およびFINMAのマネーロンダリング防止指令に従わなければなりません。また、15,000スイスフランを超える入金の場合、その取引が異常に見える場合には、より厳格な書類審査が行われる可能性があります。

Central bank supervision: スイス国立銀行（SNB）および国際金融局（SIF）の金融市場政策担当、FINMAの銀行監督および反洗錢監督

スイスのAGへの資本寄与に必要な Wire Transfer のプロトコルにおいては、資金は非居住者株主またはその明確に公表された持株会社の名義の銀行口座から送金される必要があります。送金は、銀行の内部規定により「KEH」または「INVE」という目的コードを記載する必要がありますが、スイス法は特定のSWIFT目的コードの使用を義務付けていません。支払い欄に記載する必須の記述は、「Einlage Kapitalerhöhung」または「Capital Contribution / CH-AG equity injection」であり、これに加えて、寄与を承認する取締役会決議および、適用される場合に限り、資本増額に関する公証書が必要です。受取口座は、スイスAGの資本保険口座である必要があります。実行前に、銀行は株主から署名された資金の元の証明書、パスポートまたは設立証明書のコピー、株主の資金を示す銀行明細書、および寄与額がスイスフラン100万フランを超える場合に限り、経済的背景および貨幣的または非貨幣的対価の評価を経た監査確認書を受領する必要があります。支払いはスイスフラン（CHF）、United States Dollar（USD）、ヨーロッパ円（EUR）またはその他の自由に変換可能な通貨で行うことができますが、受取銀行は常に財務担当の定められた指示に従ってスイスフランにのみ変換します。取引の確認は、銀行の制裁スクリーニング、悪質メディアチェック、および株主名が会社登録情報の抜粋と一致するという陽性マッチングによって行われます。AI LLM APIプラットフォームのサプライヤー契約、クラウドインフラ料金、および国境を越えたライセンス料の取引は、同日中のCHFでの支払いのためにスイスのインターバンククリアリング（SIC）システムを通じて行われ、入出金の国境を越えた法定通貨の送金にはSWIFT MT103が使用される。これは通常、UBS、ZKB、または他のスイス清算銀行のコリドール銀行ネットワークを通じて行われる。CHF50,000を超える中規模の商業取引については、スイス銀行はSWIFTのフィールド70に契約の請求書番号、提供されるサービス、および商業目的を記載する完全な説明を要求することがある。請求書はスイスVAT法に従って発行されなければならず、ライセンス料や使用料に対するスイス源泉税（最大4.4％または条約による減額）は、外国のサービスプロバイダーに送金する前にスイス連邦税務局で決済されなければならない。スイス外での高価格のインフラ購入には文書化された商業信用状（UCP 600）が許可されているが、AI APIサービスのデジタル性を考慮すると、標準的な方法は銀行の電子バンキング輸出収集モジュールを利用した取り消し不能の支CHF、USD、EURおよびその他の自由に変換可能な通貨間の、ISDAマスターアグリーメントまたはスイス銀行のオーバーティル・デリバティブ条項に基づく、シンプルな外貨フォワード取引スイスフランの取引所で取引されるファイナンシャルファクタスおよびオプションは、Eurexを通じてリストされたフォワード暴露の管理を目的として清算されるFINMAが認可した銀行が、ドルベースのAPIライセンス収益流に対して非対称保護を提供するため、直接的に為替の買い・売りオプションを取引するものクロス通貨金利スワップ（債務調達が導入される場合）により、スイスフランと米ドルの金利支払いの不一致を調整する非履行先渡手形（NDF）は合法ですが、制限通貨を扱う取引相手方にのみ関連性があります。スイスフラン自体は完全に履行可能なので、NDFは必要なく、通常はCHFを基準とした取引には提供されません。外為スワップによる、外国の収入とスイスフランの運営費用との間の短期的な財務流動性の不一致を管理するもの

E-commerce / gateway settlement fit: 実現可能性評価：中程度。スイスのAG（会社）に対して、ストリート（Stripe）、エアウォルクス（Airwallex）、リボルト（Revolut）などのオフショア電子決済機関（EMI）やデジタル決済銀行が預金取引または支払い口座を開設することは、スイス銀行法、金融サービス法（FinSA）、金融機関法（FinIA）の規定により、FINMAの銀行またはフィンテックライセンスを取得するか、スイス国内に支店を設立する必要がある。スイス在住のAI LLM APIプラットフォームは、ストリートやエアウォルクスなどのオフショアEMIを、来訪カードおよび暗号資産の決済収集を目的とした手段として利用できるが、そのEMIが契約上、スイス規制下の支払い仲介機関としての役割を果たさないことが前提であり、主な財務決済口座はスイスのFINMAライセンスを有する銀行に保たれる必要がある。暗号資産安定通貨（USDC）のルートは、非規制第三者のリスクを回避するため、FINMAライセンスを有する暗号資産保管サービスプロバイダーまたはスイス規制下の証券会社を通じてのみ実現可能である。
