法定实缴资本与验资锁资账户流程 强制验资锁定

根据法规，公司的最低名义股本为100,000瑞士法郎（第621条）。在注册时，每股股票的面值中至少必须有20%以现金支付，且总额不得低于50,000瑞士法郎（第632条）。这些资金必须存入一家持有执照的瑞士银行中，以公司名义设立的冻结托管账户；银行会出具支付确认书，而董事会在注册之前不得自由处置这些资金。实物出资则需有专门的审计报告，并在公司章程中予以披露。

注资与解冻路径: 按VKF/AEAI标准由州消防警察和建筑保险机构提供的消防安全认证；结构载荷检测，确认楼面承载能力以满足高价值存储架的使用要求；紧急疏散及灭火装置方案；根据州民防法规履行的民防义务；以及依据劳动法（ArG）取得的职业健康与安全许可，包括向SUVA进行的雇主注册及强制性工伤保险。

实缴资本规则: 根据法规，公司的最低名义股本为100,000瑞士法郎（第621条）。在注册时，每股股票的面值中至少必须有20%以现金支付，且总额不得低于50,000瑞士法郎（第632条）。这些资金必须存入一家持有执照的瑞士银行中，以公司名义设立的冻结托管账户；银行会出具支付确认书，而董事会在注册之前不得自由处置这些资金。实物出资则需有专门的审计报告，并在公司章程中予以披露。

官方税号申请基础设施

主管税务局

瑞士联邦税务管理局（Eidgenössische Steuerverwaltung ESTV / Administration fédérale des contributions AFC / Amministrazione federale delle contribuzioni AFC），官方网站为www.estv.admin.ch；此外还有电子服务平台“MeinSwissVAT”（https://mein.swissvat.ch），用于增值税注册、申报和退款事宜；各州层面的联邦/地方税务管理部门则负责直接税的征收工作。

电子政务申报门户

瑞士股份公司（AG）一旦被登记于州商业注册簿（Handelsregister / Registre du commerce / Registro di commercio）并刊登于瑞士官方公报（SHAB/FOSC/FUSC）后，即自动获得其企业识别号码（UID，即Unternehmens-Identifikationsnummer / Identificateur d'entreprise / Identificatore d'impresa，格式为CHE-xxx.xxx.xxx）。该UID由瑞士联邦统计局签发，作为法定的纳税人识别号（TIN），并在完成增值税登记审批后同时作为增值税识别号使用。增值税登记需通过MeinSwissVAT向瑞士联邦税务局（ESTV）提交，使用“增值税登记申请表”（Anmeldung zur Mehrwertsteuer），并附上公司章程、商业注册簿摘录及营业额预测。对于没有在瑞士设立注册地址的外国实体，必须证明其在瑞士具有可征税的商业联系，且在ESTV批准其获得CHE UID和增值税号码前，可能需要指定一名瑞士税务代表，通常处理周期为15个工作日。

支持身份选举表单

瑞士法律并不实行美国式的“勾选式”选举制度。可行的机制包括：(i) 参与豁免制度——对于符合条件的股息和资本收益，在税务申报时自动适用此制度（至少需持有10%的份额或100万瑞士法郎价值的资产，且持有时间不少于12个月）；(ii) 某些州实施的名义利息扣除制度；(iii) 增值税集团征收制度——将紧密持有的瑞士企业合并为一个增值税纳税人；(iv) 与州税务机构及ESTV合作的预扣税裁定制度，用于混合融资和跨境架构；(v) 过渡性特权地位——包括控股、注册地及辅助公司等地位，这些特权地位将在2025年起被逐步取消，以实施《瑞士最低税法》中的OECD全球最低税规定。

8.1%

强制登记营业额门槛 (Nexus)

上一营业年度全球 taxable 供应（不含增值税）的年营业额为10万瑞士法郎；对于向瑞士境内供应商品的外国供应商，不适用“最小金额豁免”规定，除非瑞士境内购货方适用反向征税机制；年营业额低于10万瑞士法郎的瑞士小型企业可自愿选择登记增值税；向瑞士私人消费者销售商品的外国电子商务经营者，无论其营业额如何，均需进行增值税登记。

跨境出口 0% 零税率申报条件

当供应商证明货物因供应行为而离开瑞士海关管辖区域时，从瑞士向外国地区出口的商品适用0%的零费率政策。供应商必须是经注册的出口商，且货物必须被运送到国外。与出口动产相关的服务、货运代理、仓储以及提供给外国客户的中介服务，根据B2B反向收费原则，属于零税率或不在瑞士增值税适用范围内。对于在线复古奢侈品转售业务，0%的税率要求商品从瑞士直接运送到外国客户的收货地；而来自国外仓库的配送服务（第三方配送）则不属于零税率范围，可能会产生目标国的增值税义务。

  • 海关出口申报（e-dec / SafeBorder），附有出口注册号码（海关申报 / 出口申报 / 出口声明）
  • 运输单据——提单、航空运单或CMR/CIM运单，证明货物从瑞士启运并抵达外国目的地
  • 商业发票、在线销售订单或寄售合同，以及适用情况下证明二手商品来源与价值的奢侈品鉴定证书
  • 付款证明/收款入账证明（SWIFT银行确认函、Stripe结算报告或担保账户付款记录），显示已从境外买家处收到款项
  • 运输物流报告，包含追踪事件及已签收的低价值包裹交付确认
  • 高价值奢侈品的保险单和/或原产地证明，作为价值证明文件

在瑞士，不存在实时财政结算、政府预授权或数字印章制度。电子发票在符合电子传输真实性及内容完整性要求的情况下有效，可通过认可的电子签名、EDI或安全交换协议来实现；瑞士的QR账单和eBill格式也被接受。自2026年1月1日起，向瑞士联邦政府提供的供应商必须通过SwissPeppol/Peppol网络传递结构化电子发票。增值税申报需通过MeinSwissVAT进行，按季度或半年一次进行提交，付款应在报告期结束后60天内完成。没有持续交易控制（CTC）API义务。

瑞士增值税法要求纳税人在业务记录中保留零税率证明；如果无法提供足够的出口证据，则需按8.1%的税率重新计算增值税，年利率为4.5%（自2025年1月1日起为5%），并根据《MWSTG》第100条规定，可能面临高达800,000瑞士法郎的行政罚款。根据《MWSTG》第101条，虚假的零税率申报属于税务欺诈行为，可处以最高3年的监禁或经济处罚，此外，如果属于故意行为，还可能需要承担10年内的追溯性增值税追补责任。虽然瑞士外汇管制规定没有设定180天的外汇回流期限，但跨境电子商务业务中，ESTV在审计时以180天内完成境内汇款作为文件依据；如果缺乏或存在矛盾的资金支付证明，则可能引发全面基于风险的审计、追溯性增值税追补以及处罚决定的公开。

外汇管制与央行政策诊断

经常项目兑换自由度

瑞士允许瑞士法郎在流动账户和资本账户交易中完全可兑换。没有通用的外汇管制法律，也没有外汇许可制度；对于股息分配、贷款汇回或国内公司清算所得，也没有任何限制。利润汇出仅受瑞士企业所得税以及35%的股息预扣税约束，根据适用的双重征税协定，这一税率可能会降低。以瑞士法郎、欧元、美元及其他主要货币进行的银行转账是允许的，但需经过反洗钱/客户身份识别审查、制裁风险审查以及接收或指令银行的对方尽职调查。

出口外汇强制结汇要求

瑞士没有关于出口收益必须上交的规定，也没有强制性的兑换比例要求，也不存在回国的期限限制。包括在线委托销售商在内的古董奢侈品出口商可以保留外币收益在瑞士银行账户或海外账户中，无需将其兑换成瑞士法郎。唯一的限制来自制裁措施、FINMA关于流动性管理的通知以及银行内部关于外币持仓限额的政策。

央行监管: 瑞士国家银行与联邦财政部合作；根据《货币和支付工具法》，外汇管理被放开，由FINMA进行审慎监管，由SECO负责执行制裁措施。

离岸数字新锐银行 / EMI 白名单

Stripe 适配度: High

对于离岸金融科技支付平台和数字银行提供商来说，其生存能力较为有限。它们可以作为Stripe、PayPal和Escrow Pay结算系统的补充性支付渠道，但无法根据瑞士公司法第634条成为资本托管验证的主要财务账户。获得FINMA许可或认可的瑞士银行必须持有注册股本。离岸支付平台通常可以作为多货币操作渠道使用，但需接受更严格的反洗钱审查，可能无法直接接入SIC/SIC4系统，也不适合进行大额瑞士法郎的清算业务。

跨境清算通道与结算适配

inbound股本出资通过常规的SWIFT MT103或SEPA信用转账方式，汇入瑞士资本托管账户。至少10万瑞士法郎的出资款必须在注册前被不可撤销地收到，并可由董事会自由支配。汇款信息中必须注明用途为“根据CO第632条和633条的股本出资”，并注明公司名称。不存在外汇管制问题，但运营银行会要求提供最终出资人的证明、资本释放声明，以及确认资金并非来自犯罪来源的证明。收款账户应属于FINMA许可的瑞士银行；无需事先获得外汇管制批准。出口贸易支付采用SWIFT MT103标准清算机制，用于处理瑞士法郎、欧元、美元和英镑的支付。瑞士法郎支付通过SIC/SIC4实时全额结算方式完成；欧元支付则通过SEPA和Target2系统进行；美元支付则通过银行在美国的代理行以及Fedwire/CHIPS系统进行。与拍卖商和机构发货人交易时，可通过UBS或ZKB办理商业信用证业务。所有出口支付都需要有相关合同文件、商业发票以及制裁风险筛查结果作为依据。对于买卖双方的托管流程，资金被存储在Escrow Pay账户中，在满足特定条件后，通过SEPA或SWIFT转账至经过验证的卖方银行账户。直接提供瑞士法郎/欧元和瑞士法郎/美元的即期外汇远期交易，交易对手方为瑞士或欧盟/英国银行，交易依据已建立的ISDA/CSA文件进行。外汇远期互换和跨境货币互换，用于管理多币种现金管理流动性，包括将欧元/美元销售所得转换为瑞士法郎运营现金流。用于对拍卖采购和海外库存补充产生的交易风险进行对冲的欧洲式标准外汇期权。在不常见或转换性受限的货币中，可使用非可交付远期合约，但对于瑞士法郎、欧元或美元来说通常没有必要使用，且必须由根据《瑞士金融市场基础设施法》获得许可的衍生品经纪商来操作。

转让定价与经济实质

主文档/本地文档门槛: 瑞士法律并未规定强制提交本地文件或主文件时的最低金额标准。不过，瑞士以OECD转让定价指南作为解释依据，要求纳税人在税务机关要求时提供合理的文档资料。对于集团中的瑞士子公司而言，如果其合并收入达到9亿瑞士法郎以上，则必须履行国别报告义务：该集团的瑞士子公司需向ESTV提交CbC通知，而最终母公司若为瑞士居民，则必须提交完整的CbC报告。在审计实践中，任何规模的重大跨境关联方交易——尤其是从关联人士处购买或出售的复古奢侈品复制品交易——都必须有完善的文档记录。

经济实质审查范围: 瑞士没有实行类似于欧盟或加勒比海地区经济实体规定制度的法规体系。不过，经济实体对于瑞士企业居民身份、条约相关权益、参与资格豁免以及预提税减免来说至关重要。那些董事会、企业记录、经营场所、银行账户以及实际决策权均明确位于瑞士的公司，会被视为瑞士税务居民。而那些从国外管理电子商务奢侈品转售业务的公司，则会被重新认定为从国外管理；其瑞士住所可能会被拒绝认可，其境外优势也会被取消，而集团内部支付款项则可能被重新归类为构造性股息或隐藏利润分配，需缴纳35%的瑞士预提税。

致命合规红线与董事个人责任

逃税及虚假文件

法定制裁: 对遗漏的利润及违约利息进行重新评估；行政性逃税处罚通常等于所逃漏的税款，在情节严重时可高达该金额的三倍；根据瑞士联邦直接税法，逃税行为可面临刑事起诉，并面临监禁和罚款。增值税逃税同样会引发处罚，且非法避免的增值税将被没收。

董事个人责任: 董事可能根据瑞士债务执行法，因在税务执行程序中故意耗尽公司资产而承担个人责任；欺诈性隐瞒或伪造行为可能导致刑事罚款、监禁、个人资产被没收、禁止出境以及引渡请求，以促进国际合作。
空壳公司 / 虚假实体滥用

法定制裁: 撤销瑞士税务居住权，或将应纳税利润重新归属于实际管理所在地；拒绝享受条约优惠及参与豁免待遇；对隐藏分配进行重新认定，并缴纳35%的预提税及利息；根据商业注册程序关闭公司，若注册地址不再符合实际运营地点；对迂回安排行为处以罚款和制裁。

董事个人责任: 董事们将根据瑞士义务法第754条承担连带及按比例责任，就虚假建筑行为造成的损害承担赔偿，包括返还税收优惠并支付利息、债权人提起的民事索赔、被禁止担任董事会成员、在刑事诉讼中被禁止出境，以及可能被没收从空壳结构中获得的个人利益。
转让定价操纵 / 利润转移

法定制裁: 瑞士税务机关将实施独立交易调整，拒绝认定超额支出，将差额重新归类为实质性的股息，征收35%的预提税并加收滞纳金，同时对提交不充分或虚假文件的行为处以行政罚款；若相关文件仍不充分，纳税人还可能面临瑞士联邦行政法院的争议评估。

董事个人责任: 批准非正常交易的董事，若明知使公司陷入税务欺诈，需就由此产生的未缴瑞士税款承担个人责任；当使用AG作为纯粹的附属实体以将利润转移海外时，可适用揭开公司面纱制度。民事赔偿可包括追缴税款、利息及程序性费用，若正在调查财政避税的刑事指控，还可下令禁止相关人员出境。
反洗钱/托管账户合规失败及支付渠道滥用

法定制裁: 如果联邦检察官担任金融中介或根据瑞士反洗钱法（Swiss AMLA）受监管，则违反规定将面临监管处罚、罚款和关闭命令；根据瑞士刑法，洗钱行为将面临监禁和罚款，相关资产（包括为转售而持有的奢侈品）将被没收。若将托管业务视为金融中介活动，则可能需要获得特定行业的许可。

董事个人责任: 参与或纵容洗钱结构的董事可能将因洗钱或未履行审慎核查义务而被个人追究刑事责任，面临监禁、个人银行账户被查扣、旅行禁令、资产冻结、资格取消以及非法所得的民事追缴；董事还可能被责令偿还公司因违反职责而产生的罚款、罚金及法律辩护费用。
