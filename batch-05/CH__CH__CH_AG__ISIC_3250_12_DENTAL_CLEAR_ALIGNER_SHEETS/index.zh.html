外汇管制自由度 瑞士对瑞士法郎实行完全的资本和经常账户可兑换制度。没有外汇管制，也没有关于出口收益必须上交的规定，跨境转账也不需要中央银行的批准，将瑞士法郎兑换为其他货币也不受限制。外国投资者可以自由地注入股权和债务资本，瑞士股份有限公司也可以无需经过外汇管理部门的审批即可向国外支付股息、利息、特许权使用费或服务费。唯一的实际障碍与税收相关：股息等利润分配需缴纳35%的瑞士预提税；如果受益所有人符合双重征税协定待遇、瑞士国内参与豁免条款或瑞士母子公司机制，则无需缴纳该税款。同等级别的贷款利息、商业交易款项及工资报酬在无需预提税的情况下也可以跨境支付，前提是接收方不承担瑞士的信托义务。瑞士法郎本身完全具有可兑换性，定价和发票金额可以用瑞士法郎、欧元、美元或任何约定的货币来表示。

外国实体或其瑞士分支机构/股份公司必须首先在州级层面向瑞士商业登记处（Handelsregister）注册，以获得瑞士公司识别号码（UID，Unternehmens-Identifikationsnummer）。就增值税而言，该实体须向联邦税务管理局（ESTV）提交增值税注册表（Registrierung für die Mehrwertsteuer）或通过电子门户完成注册。如果该实体在瑞士开展应税活动，且其全球年营业额超过瑞士境内商品或服务交易的10万瑞郎，或从境外向瑞士供应应税商品或服务且交易额超过10万瑞郎，则必须进行注册。ESTV将向该实体颁发一个独立于UID的增值税号码（MWST-Nr / Numéro IDE / No IVA）。非居民实体若未在瑞士设立，且无瑞士居所或常设机构，必须指定一名在瑞士有住所的瑞士税务代表，以履行增值税申报和缴税义务。UID申请须在业务启动后30天内提交；增值税注册申请须在应税活动开始前或一旦超过门槛时立即提交。

瑞士法律并不存在与美国类似的可选择的间接传递机制。不过，根据《瑞士增值税法》，营业额低于10万瑞士法郎的企业可以选择自愿登记增值税，且需承诺至少两年不撤销该选择。根据《瑞士增值税法》第20条，瑞士企业可以在普通增值税征收和增值税集团征收之间选择一种方式，从而让紧密关联的纳税人被视为一个统一的纳税实体。在公司所得税方面，瑞士法律提供了一些法定选择：例如，对符合条件的股息和资本收益适用瑞士参与优惠制度；在仍允许设立这种状态的州，可以按照州级控股公司或混合公司的身份进行征税；根据《瑞士合并法》，企业重组需要获得批准而非单方面选择。根据《瑞士增值税法》第8a条及其相关法规，混合不匹配情况下的规则选择并非可选择的选项，只是会拒绝某些扣除或重新认定支付行为，但纳税人可以在规定的范围内选择适用的规则。联邦法律不允许一次性选择视为清算或升级措施，除非是特定的重组情况。

跨境出口 0% 零税率申报条件

根据瑞士增值税法第23(1)条和第53条，有形动产向国外出口时可享受零税率（税率为0%），前提是供应商能够证明这些商品在法定期限内被运送到国外，且外国收货人即为购买方。如果商品是由供应商、接收方或接收方指定的第三方实际出口的，且目的地位于国外（而非如萨姆纳恩这样的瑞士海关免税区），则也属于此类情况。与出口商品相关的服务（如运输、装卸等）以及某些跨境服务（包括知识产权许可、未在瑞士使用的对外国接收方的服务）也符合增值税法第23(2)条和第53条的规定，只要接收方的注册地址或住所位于国外。对于通过市场平台或Stripe进行的销售，供应商必须根据增值税法第7-8条确定供应地点：如果商品被放入瑞士并运往国外，且运输从瑞士开始并在外国结束，则属于出口行为。由瑞士公司生产并销售给外国正牙医生的牙齿矫正器，如果被寄往非瑞士地址且正确申报，也可享受零税率。输入增值税的退还仅适用于通过增值税申报表进行的出口业务（即负增值税状态），这需符合增值税法第28-32条规定的一般抵扣权利；此外，未设立实体的外国企业也可以根据瑞士增值税退税程序（表格30）申请退还在瑞士购买的商品或服务的增值税，但需遵循互惠原则。

瑞士目前并不采用需要税务机关事先批准才能开具的实时税务清算或连续交易控制模式。只要电子发票包含所有法定数据字段，且来源真实性、内容完整性及可读性得到保障，即可按照常规增值税发票规则进行使用。公认的电子发票标准包括瑞士电子发票格式（基于Peppol BIS标准、XML/UBL 2.1格式，或如Swico或EBill这样的瑞士专用格式，用于消费者支付）。自2024年1月1日起，瑞士支付发票必须在以瑞士法郎计算的国内B2B和B2C发票上显示QR码（QR-IBAN）；对于非瑞士法郎的外国交易，仍可继续使用旧式支付单。没有强制性的数字印章或税务印章要求。发票必须保存10年。根据瑞士增值税法，对于金额超过400瑞士法郎的B2B交易，必须出具完整的增值税发票；对于B2C交易，金额低于400瑞士法郎时，简单的发票即可满足要求。对于营业额超过100,000瑞士法郎的企业，必须通过电子方式提交申报（通过eService或瑞士dec认证软件提交增值税申报），无需在提交截止日期前定期向税务机关提交实时数据。

瑞士联邦税务局对符合零税率出口商品会进行严格审查，并要求提供相应的文件证明。如果出口商未能在法定期限内证明其出口行为，该商品将被重新归类为国内应税商品，并按标准税率征收增值税，同时还会附加利息处罚。根据《瑞士增值税法》第69条，逃税行为可处以最高3倍于逃税金额的罚款；根据第70条，轻微违规行为则处以警告或最高8,000瑞士法郎的罚款；根据第66-68条，违反记账及其他义务的行为则处以最高5,000瑞士法郎的罚款（严重情况可达10,000瑞士法郎）。对于欺诈性零税率出口行为，根据《瑞士刑法》及《增值税法》第186-188条，可处以最高5年的监禁等刑事处罚。对于逃税行为，追溯期可延长至10年；对于普通增值税违规行为，追溯期为5年。出口商必须保存出口文件10年；若无法提供相关文件证明，则将被拒绝享受零税率待遇，并按8.1%或适用较低税率重新征税。此外，根据《行政处罚法》（2019年）规定，海关可处以最高20,000瑞士法郎的罚款，对于虚假申报或错误分类行为，还可没收货物。联邦最高法院要求必须具备真实的商业目的及实际运输证明；循环交易或壳公司中介行为将被视为不正当行为而受到质疑。

外汇管制与央行政策诊断

经常项目兑换自由度

瑞士对瑞士法郎实行完全的资本和经常账户可兑换制度。没有外汇管制，也没有关于出口收益必须上交的规定，跨境转账也不需要中央银行的批准，将瑞士法郎兑换为其他货币也不受限制。外国投资者可以自由地注入股权和债务资本，瑞士股份有限公司也可以无需经过外汇管理部门的审批即可向国外支付股息、利息、特许权使用费或服务费。唯一的实际障碍与税收相关：股息等利润分配需缴纳35%的瑞士预提税；如果受益所有人符合双重征税协定待遇、瑞士国内参与豁免条款或瑞士母子公司机制，则无需缴纳该税款。同等级别的贷款利息、商业交易款项及工资报酬在无需预提税的情况下也可以跨境支付，前提是接收方不承担瑞士的信托义务。瑞士法郎本身完全具有可兑换性，定价和发票金额可以用瑞士法郎、欧元、美元或任何约定的货币来表示。

出口外汇强制结汇要求

在瑞士，没有法定要求要求出口商将出口收入交给SNB，或将外币收入兑换成瑞士法郎。出口收入可以保留在瑞士银行中可自由兑换的外币账户中，也可以由瑞士出口商自行决定存入任何外国银行账户。瑞士法郎在SNB的货币政策指导下，通过灵活的汇率政策自由波动。对于出口收入而言，没有强制兑换比例、回国期限或FINMA审批要求。不过，出口交易仍受常规的反洗钱和制裁合规要求约束；在出现异常情况时，接收银行必须能够确定相关的商业背景、实际受益方以及资金来源。就瑞士增值税而言，出口收入通常被视为零税率供应，但税收状态对外汇返还义务并无影响。

央行监管: 瑞士国家银行（SNB）；对银行和金融市场基础设施的监管工作由瑞士金融市场监督局FINMA（Eidgenössische Finanzmarktaufsicht）负责。相关法律框架包括《货币和支付工具联邦法》、《1934年银行法》（经修订）以及FINMA的反洗钱法规。

低至中等风险。瑞士并非欧洲经济区的成员国，因此在英国、立陶宛或新加坡获得许可的离岸电子货币机构无法在瑞士享受欧盟支付服务便利。希望为瑞士企业提供账户或支付服务的离岸电子货币机构，必须依靠拥有瑞士许可的合作伙伴银行进行SIC和SEPA结算，或者根据瑞士银行法第1b条获得瑞士金融科技许可，但此类许可仅限于不超过1亿瑞士法郎的存款，并需接受FINMA的监管。对于风险较低的牙科矫正器制造商而言，选择一家信誉良好的瑞士一级银行比使用金融科技类电子货币机构更为实际且成本更低，因为该银行能够提供必要的文件交易设施、通过SIC进行的瑞士法郎清算服务，以及适合国际正畸产品分销商使用的可靠银行合作关系。离岸数字电子货币机构只能作为市场交易的补充支付渠道使用，不建议作为主要的财务银行。

跨境清算通道与结算适配

公司的初始资本为100,000瑞士法郎，必须以公司名义存入冻结或托管账户，之后才由商业登记处颁发公司注册证书。选定的瑞士银行将提供资本托管存款确认书，而认购资金必须来自股东名下的可验证银行账户；如果由第三方出资，则须有书面指定资金声明，说明相关的资本关系。所有资金必须通过SWIFT MT103方式发送，使用银行自身的结算身份信息；汇款人字段应与股东姓名一致，而“额外付款”字段则明确标明是瑞士公司。这家瑞士银行将要求提供公证的资本支付证明的原件或经认证的副本，并且只有在公司登记信息完成之后，才会将资金转至公司的运营账户。无需进行外汇申报或SNB批准，但付款说明应写为“Sacheinlage / 资本出资”或“股份资本出资——公司注册”，且资金来源证明必须根据瑞士反洗钱规定保存十年。这家瑞士公司主要通过SIC（瑞士银行间清算系统）、SEPA（在欧洲经济区以欧元结算时）以及SWIFT MT103消息来办理与美元、人民币或其他可兑换货币相关的跨境支付。关于牙科矫正器片和定制式托盘的出口货物，则通过不可撤销的跟单信用证进行结算，该信用证以瑞士公司为受益人；或者用于瑞士公司自身购买PETG共聚物和自动修剪设备的支付；又或采用具有明确付款条件的电汇方式。对于商业信用证交易，开证银行会将SWIFT MT700消息转发给瑞士通知银行，而瑞士受益人则需提供符合要求的文件（商业发票、包装清单、原产地证明、空运单/提单，以及必要的卫生和MEDDEV认证文件），以便接受银行进行支付。通过使用符合UCP600标准的不可撤销信用证，可以降低出口风险，尤其是在涉及新兴市场的分销商时。对于向供应商的直接支付，瑞士公司应仅通过经过验证的企业互联网渠道进行，并需获得双重授权；同时必须包含银行批准的用途代码（例如“商品——医疗设备”），并保留有相关运输文件的商业合同，以满足账户关系审查和合规要求。与瑞士持牌信贷机构或其集团财团签订的可交付远期外汇合约标准外汇掉期，用于即期与远期同时结算香草型外汇期权（欧元、美元、人民币和瑞士法郎的看涨/看跌期权）经银行衍生品交易部门批准的障碍期权和结构化远期产品外币利率互换（CIRS），用于非瑞士法郎本地货币借款在受监管的欧盟和瑞士交易所交易外汇期货，其中瑞士银行担任清算成员非交割远期（NDF）若交易对手银行将该工具用于管理结算货币的可兑换限制，但对瑞士法郎（CHF）并非强制要求。外汇参与远期和普通资产互换仅用于对冲基础采购和分销风险，不得用于投机性现金管理操作

电商与网关结算适配度: 低至中等风险。瑞士并非欧洲经济区的成员国，因此在英国、立陶宛或新加坡获得许可的离岸电子货币机构无法在瑞士享受欧盟支付服务便利。希望为瑞士企业提供账户或支付服务的离岸电子货币机构，必须依靠拥有瑞士许可的合作伙伴银行进行SIC和SEPA结算，或者根据瑞士银行法第1b条获得瑞士金融科技许可，但此类许可仅限于不超过1亿瑞士法郎的存款，并需接受FINMA的监管。对于风险较低的牙科矫正器制造商而言，选择一家信誉良好的瑞士一级银行比使用金融科技类电子货币机构更为实际且成本更低，因为该银行能够提供必要的文件交易设施、通过SIC进行的瑞士法郎清算服务，以及适合国际正畸产品分销商使用的可靠银行合作关系。离岸数字电子货币机构只能作为市场交易的补充支付渠道使用，不建议作为主要的财务银行。

转让定价与经济实质

主文档/本地文档门槛: 如果集团的合并收入超过5000万瑞士法郎，且公司间交易金额超过500万瑞士法郎（按交易类型计算），则需要提供本地文件和主文件。对于规模较小的企业，建议采用简化的文档形式（同时进行的TP研究）。

经济实质审查范围: 与阿联酋不同，瑞士没有类似正式的经济实体法规，但《控股公司税收处理法》和《参与优惠规定》要求企业必须拥有真正的经济实体（如员工、办公场所及决策机构），才能享受参与优惠或条约福利。经合组织关于利润侵蚀和利润转移的举措，尤其是第5项措施，也要求知识产权控股公司必须开展实质性的业务活动。对于牙科矫正器制造商而言，其经济实体可通过在瑞士进行的研发、生产和管理活动来证明。

致命合规红线与董事个人责任

逃税

法定制裁: 罚款最高可达逃避税额（联邦和州级）的三倍，并加收利息。刑事起诉可能导致最高三年监禁。

董事个人责任: 董事及高级管理人员若明知参与或未采取行动，可能就逃税行为承担个人责任，包括民事追缴逃税款项、旅行禁令以及根据相互法律协助条约可能被引渡。
空壳公司 / 缺乏经济实质

法定制裁: 拒绝享受税收协定待遇、收入重新分类，以及对视为分配的收入征收35%的预提税。未符合实质要求将处以最高不超过10万瑞郎的罚款。

董事个人责任: 董事若明知协助了空壳结构，可能需就未缴的预提税及罚款承担个人责任，可能被实施旅行禁令和资产冻结。
反洗钱/洗钱

法定制裁: 对公司处以最高达50万瑞士法郎的刑事罚款，并对个人处以监禁。监管处罚包括吊销许可证和禁止参与公共采购。

董事个人责任: 董事可能面临最高五年监禁和个人罚款。对第三方造成的损害承担民事赔偿责任。旅行禁令和资产冻结较为常见。
转移定价虚假申报

法定制裁: 调整应税收入，处以额外税额20%至50%的罚款及利息。在严重情况下，将追究逃税的刑事责任。

董事个人责任: 董事若批准了非公允价格的交易，可能需就额外税款承担个人责任。还可能面临旅行禁令和职业资格取消。
