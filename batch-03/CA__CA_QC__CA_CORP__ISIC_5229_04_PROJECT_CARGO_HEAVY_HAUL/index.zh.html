外汇管制与央行政策诊断

经常项目兑换自由度

加拿大对经常项目和资本项目均保持近乎完全可兑换。《货币法》（R.S.C., 1985, c. C-52）确立加拿大元为法定货币，但允许以任何自由兑换的外币进行合同结算。对于魁北克公司而言，利润汇出、股息支付、贷款偿还及资本返还均不受外汇管制限制，但须符合《魁北克公司法》（CQLR c S-31.1）下的偿付能力测试，以及针对股息和利息的非居民预提税（通常在税收协定下可减免15%至25%）。项目货物实体可自由以加元、美元、欧元或其他货币开具发票并收款。股权流入和贸易流出款项无需获得加拿大银行的批准。GST/HST及魁北克税务局（Revenu Québec）的注册属于独立的税务义务，而非外汇管制措施。

出口外汇强制结汇要求

没有。自1951年以来，加拿大从未对出口收入实施外汇交还或汇回国内的要求。那些从事长途物流业务的企业无需在规定的期限内将外币收益汇回国内，也无需将其兑换成加元。根据《海关法》和《统计与人口普查法》，出口发票必须保留用于税务、统计和海关目的，但并没有关于银行转换的强制要求。所有结算款项仍可以保持原合同所使用的货币形式。

央行监管: 加拿大银行（Banque du Canada）；在加拿大灵活汇率制度下，加拿大财政部与加拿大银行共同行使外汇管理职能，而FINTRAC负责反洗钱/反恐融资义务。加拿大没有专门的外汇管制机构。

离岸数字新锐银行 / EMI 白名单

Cross-border EMI / Fintech rails 适配度: High

可行性评级：低至中等。根据《犯罪所得（洗钱）及恐怖融资法》（SC 2000, c 17）及FINTRAC的相关规定，任何在加拿大开展业务的境外数字电子货币机构（EMI）必须在加拿大注册为货币服务业务（MSB）。未注册的境外EMI不得为前往加拿大的项目账户提供支付服务。境外EMI账户并非由持牌银行保障的存款账户，也无法可靠地为高价值里程碑提供MasterCard/Visa结算服务。只有在EMI已注册于FINTRAC并具备接受资金汇款文件准备能力的情况下，方可用于辅助性、低价值款项的收取。主要的现金管理、资本注入、信用证及清算需求必须通过加拿大《第I类或第II类银行》处理。因此，现金管理政策应将EMI定位为“钱包型”二级账目，绝不能将其视为银行清算账户。

账户名称和交易活动显示高价值的跨境供应商汇款流向存在高度制裁风险的国家

风险根因: 账户名称和交易活动显示高价值的跨境供应商汇款流向存在高度制裁风险的国家

防御与化解材料: 已执行的主物流服务协议；超限货物运输的商业发票及形式发票；供应商入驻文件，包括营业执照、制裁筛查阴性结果及银行交易对手信息；符合FINTRAC要求的交易监控说明。
无加拿大信用记录，无实质性经济联系，所有董事均为非居民

风险根因: 无加拿大信用记录，无实质性经济联系，所有董事均为非居民

防御与化解材料: 魁北克办公场所或保税码头租赁协议；魁北克交通部针对超尺寸货物的许可文件；魁北克税务局的GST/QST注册证明或自愿注册证书；公用事业账单或租赁凭证；一年期项目计划表以及确认大宗运输合作的加拿大客户信件。

跨境清算通道与结算适配

所有境外股权注入均应通过股东银行向加拿大银行清算账户发送SWIFT MT103/MT202 COV汇款。汇款指令必须包含受益人账户号码（CIS）、用于直接投资的ISO付款目的代码（例如：“直接投资—股权资本”或“股权注入”）、说明“为魁北克项目货物公司进行股本注入”的文字叙述以及完整的汇款人身份信息。对于金额超过10,000加元的汇款，加拿大银行将核实资金来源，并可能要求汇款银行提供账户结余确认函。资金须经FINTRAC制裁筛查，并依据公司认缴账目核对后，方可入账至运营账户。若该股权注入以股东债务形式结构化，汇款指令中应包含贷款协议及转让价格文件，以避免税务重新定性。股息、管理费及特许权使用费的支付属于不可控事项，但根据《所得税法》第十三部分规定的预扣税，企业须在支付源头履行代扣义务。重型设备交易结算以及项目货物分包商的里程碑款项，应通过以下渠道进行支付：(1) 使用SWIFT MT103方式向直接供应商和分包商支付款项，包括收款人的完整账户信息及交易发票参考号。(2) 用于购买大型设备或基于里程碑的EPC付款的商业信用证（SWIFT MT700/MT707）；(3) 使用SWIFT MT400/MT422的跟单托收方式（D/P和D/A），以分期付款方式进行支付。(4) 超过50,000加元的CAD交易，通过加拿大支付局运营的“大额转账系统”进行清算，使用银行的清算代码和结算账户；(5) 美元交易则根据下游银行的情况，通过代理银行网络、CHIPS或Fedwire进行清算。每根出口电线都必须与相应的商业发票相关联，而加拿大银行的反洗钱模型则必须与OSFI/DPR制裁名单上的收款人一致。如果涉及《出口和进口许可法》规定的受管制商品，则必须附加额外的海关许可文件。交付加元货币对（美元/加元、欧元/加元、英镑/加元）的标准化外汇远期合约，依据1998年ISDA外汇与货币定义以欧洲式外汇期权形式交易加元货币对的期权，包括已货币化的抵押品的看跌期权和看涨期权仅限于新兴市场货币（如人民币、印度卢比、巴西雷亚尔）的非交割远期（NDFs），这些货币的外币交割被禁止或流动性不足；加元（CAD）本身可完全交割。交叉货币利率互换（CIRS），将加元借款与美元/欧元项目收入流相链接外汇掉期及远期-次日滚动交易用于临时流动性管理

电商与网关结算适配度: 可行性评级：低至中等。根据《犯罪所得（洗钱）及恐怖融资法》（SC 2000, c 17）及FINTRAC的相关规定，任何在加拿大开展业务的境外数字电子货币机构（EMI）必须在加拿大注册为货币服务业务（MSB）。未注册的境外EMI不得为前往加拿大的项目账户提供支付服务。境外EMI账户并非由持牌银行保障的存款账户，也无法可靠地为高价值里程碑提供MasterCard/Visa结算服务。只有在EMI已注册于FINTRAC并具备接受资金汇款文件准备能力的情况下，方可用于辅助性、低价值款项的收取。主要的现金管理、资本注入、信用证及清算需求必须通过加拿大《第I类或第II类银行》处理。因此，现金管理政策应将EMI定位为“钱包型”二级账目，绝不能将其视为银行清算账户。
