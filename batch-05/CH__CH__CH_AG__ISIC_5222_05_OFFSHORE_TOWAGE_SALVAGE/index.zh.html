外汇管制与央行政策诊断

经常项目兑换自由度

根据外汇条例第1条，瑞士在经常账户和资本账户方面都允许瑞士法郎完全且无限制地兑换。对于跨境支付、股息分配、资本回流、贷款服务以及海上救助和拖船索赔的结算而言，无需事先的行政批准、中央银行许可或外汇管制许可证。瑞士法郎具有自由浮动的特性，不受任何兑换或转换限额的限制。实际障碍主要限于：(i) 对源自瑞士的股息征收的35%法定预提税，该税率可降至0%，或在符合相关双重征税条约的情况下被部分退还给实际受益人；以及(ii) 瑞士银行对于每月超过2500万瑞士法郎的个别跨境交易所必须进行的国际收支统计报告义务，这属于统计披露要求，而非对兑换能力的限制。对于从事深海拖船和海上救助业务的瑞士公司来说，使用瑞士法郎、欧元或美元进行报价，或在FINMA监管下的银行中持有外币账户，均不受外汇管制限制。

出口外汇强制结汇要求

没有适用的规定。瑞士不对出口收益的遣返设定法定时间限制，也不要求进行强制兑换，更没有要求将外币出口收入存入境内账户的要求。从事海外拖航和打捞业务的瑞士股份公司可以无限期地保留以瑞士法郎、欧元或美元计价的应收款项，这些款项可以存放在境内或境外账户中。唯一的合规要求是：(i) 公司的年度财务报表必须根据瑞士通用会计准则FER反映相应的货币风险；(ii) 在一个日历月内，金额超过2500万瑞士法郎的跨境交易必须由瑞士银行向SNB报告，以便纳入国际收支统计中；(iii) 从打捞仲裁中获得的收入（例如劳埃德公开形式裁决所得）必须通过瑞士监管的支付渠道进行清算，以满足FINMA第2016/07号通知中的严格审查要求。没有对冲义务，收到收入时无需进行兑换，持有外币出口收入也没有任何处罚。

转让定价与经济实质

主文档/本地文档门槛: 对于拥有至少9亿瑞士法郎合并集团收入的瑞士母公司或外国集团下属实体，必须进行按国家进行的报告义务；瑞士没有固定的法定本地文件/主文件金额门槛，但税务机构可根据风险情况要求提供相关文件；对于海上拖航和打捞业务实体，当公司间营业额超过100万瑞士法郎时，强烈建议进行符合OECD标准的转移定价研究。

经济实质审查范围: 瑞士通过《海上航行联邦法》实施经济实质原则——在瑞士注册船只、拥有法定船籍以及进行有效统一管理，是享受直接税航运免税待遇的前提条件；根据OECD包容性框架以及瑞士关税协定中的现代LOB/PPT条款，由外国母公司持有被动拖航合同的壳公司无法获得条约优惠，35%的关税优惠被重新实施，而海事税收特权则被追溯取消。

致命合规红线与董事个人责任

逃税 — 税务欺诈

法定制裁: 在延长的限制期内进行重新评估（故意隐匿行为为10年）；逃避缴纳的联邦和州税款需缴纳三分之一的罚款，若使用伪造文件则须缴纳三分之二的罚款（《税务法》第175条）；税收欺诈行为（《税务法》第186条）可处以最多2年的监禁或高达10,000瑞士法郎的罚款；为保障税收索赔，该船只可能被实施海上扣押。

董事个人责任: 签署或纵容虚假声明的董事将被视为法人主体而承担刑事责任（《瑞士刑法典》第12条），可能面临个人监禁和罚款，并根据《瑞士刑法典》第754条或规定，对逃避的税款承担连带及按份的民事赔偿责任；瑞士税务刑事程序还允许对境外居留的被告实施禁止出境措施，并可查封其私人银行账户。
空壳公司 / 条约购物 / 缺乏实质

法定制裁: 拒绝瑞士税收居民地位及税收协定优惠；重新评估外国控股公司所获收入；对所有分配追溯适用35%的预提税；依据瑞士相互协助法进行信息交换；注销瑞士籍船舶登记并撤销其航行许可证。

董事个人责任: 董事会可能因未支付关税及税款以及违反企业宗旨而受到诉讼（第717条）；那些故意促成这种人为结构形成的董事，将因虚假陈述行为面临刑事制裁，可能被从商业登记册中除名，并禁止未来担任相关职务；根据瑞士刑事诉讼程序法，他们还可能面临退出限制和引渡风险。
转移定价操纵 / 隐性利润分配

法定制裁: 以合理商业原则进行调整，将差额重新分类为隐性股息，适用35%的预提税并加收滞纳金；对故意定价不当行为处以最高不超过逃避税额三分之一的处罚（《DBG法》第175条）；州税务机关可发出文件要求，并对逾期提交处以每日罚款。

董事个人责任: 批准非公允交易的董事须就由此产生的税款缺口及预提税承担个人责任（依据第754条）；在发票伪造的情况下，董事将面临税务欺诈罪的监禁及个人罚款；外国母公司将通过瑞士的执行程序间接受到影响。
