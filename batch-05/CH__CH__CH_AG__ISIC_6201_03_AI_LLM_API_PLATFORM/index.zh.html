瑞士法律中不存在“勾选式制度”。法定选举仅限于增值税集团征税（增值税法第14条）以及联邦税收集团征税（“Steuerliche Tragerschaft”/“group制度”），符合条件的瑞士集团企业可以选择作为单个联邦利润税单位进行征税。根据瑞士国内法律，无法实施混合不匹配选举制度。

跨境出口 0% 零税率申报条件

货物在瑞士境内实际出口并提供出口证明的，可享受0%增值税。对于人工智能大语言模型（AI LLM）API平台而言，向境外企业客户提供的离岸数字/数据库服务，根据“供应地规则”属于瑞士增值税的豁免范围，或在接收方为非瑞士企业且保留了境外实体的文件证明的情况下，可享受零税率。然而，向瑞士私人消费者的提供服务则不符合出口零税率的条件。

  • 海关出口申报（出口许可证 / 通过瑞士海关电子申报流程申报）
  • 提单或空运提单（国际运输凭证）
  • 汇入款项证明或外币银行信贷证明（付款凭证）

瑞士并不实行实时财政结算、印章处理或政府规定的发票API审批机制。瑞士的QR票据要求适用于支付文件。增值税合规问题则通过ESTV安全电子服务门户提交的定期申报表来解决，电子记录被接受，但不存在持续交易控制的审批要求。

ESTV通过比对出口申报、国际运输单据、合同及付款凭证来审核免税申报。对于无法提供依据或虚假的免税申报，将予以撤销，并重新评估，加收滞纳金及行政罚款。故意逃避增值税的行为将面临刑事罚款，甚至可能被判处监禁，税务欺诈案件的追溯重新评估期限为10年；一般情况下，税务评估期限为5年。瑞士法并未规定外汇回流的法定截止期限，但在出口真实性审查中，行政上会采用180天作为付款核对的基准。

外汇管制与央行政策诊断

经常项目兑换自由度

瑞士实行完全自由化且可兑换的货币制度，资本交易与经常账户交易之间没有任何区别；非居民可以自由持有瑞士法郎，并以任何可兑换货币将股息、利润、特许权使用费及资本汇回本国。盈利款项汇出或资本返回无需事先许可，只需遵守瑞士银行所必须遵循的标准反洗钱规定即可。瑞士法郎不受外汇管制限制，外币账户也无限制，但瑞士国家银行仍拥有法定权力，在特殊情况下采取临时保护措施，包括负利率和强制储备要求，不过这些措施历史上主要针对国内流动性，而非跨境可兑换性。

出口外汇强制结汇要求

瑞士没有规定出口收益的移交或遣返的时间限制，也没有强制性的货币兑换比例要求；出口商和数字服务提供商，包括人工智能API平台，可以自由保留、再投资或将在外币账户中收到的款项在银行间市场进行兑换。不过，银行客户仍需遵守瑞士义务法及FINMA反洗钱法规，在通过瑞士银行账户处理出口收入时，必须明确其经济背景和资金来源；如果 inward支付金额超过15,000瑞士法郎，且交易行为显得异常，则可能需要进行更严格的文件审核。

央行监管: 瑞士国家银行（SNB）与联邦国际金融局（SIF）负责金融市场监管，以及金融市场监管局（FINMA）负责银行业监管和反洗钱监督

符合瑞士股份公司（AG）资本注入要求的电汇协议规定，资金必须从非居民股东或其明确披露的持股实体名下的银行账户中划出。电汇应按照银行内部操作惯例注明目的代码“KEH”或“INVE”，尽管瑞士法律并未强制要求使用特定的SWIFT目的代码；付款信息中的必填说明应明确标注“Einlage Kapitalerhöhung”或“Capital Contribution / CH-AG equity injection”，并附上经董事会批准的资本注入决议，如适用，还需附上经公证的注册资本增加文件。收款账户必须为瑞士股份公司的资本保证金账户。在执行前，银行须收到股东签署的出资来源声明、护照或公司注册证明文件的复印件、显示股东资金的银行对账单，以及当出资额超过100万瑞士法郎时，需提供经审计的经济背景说明及任何货币或非货币性对价的估值确认。付款可采用瑞士法郎（CHF）、美元（USD）、欧元（EUR）或任何可自由兑换的货币；接收瑞士银行仅根据预先设定的财务指令将外币兑换为瑞士法郎。交易的合规性核查通过银行的制裁筛查、负面媒体报道核查以及股东姓名与公司注册信息摘要的正向匹配完成。针对AI LLM API平台与供应商合同、云基础设施支付以及跨境许可费相关的交易，通过瑞士银行间清算系统进行当日国内瑞士法郎支付；而跨境法定货币交易则通过SWIFT MT103方式进行，通常借助UBS、ZKB或其他瑞士清算银行的走廊银行网络来完成。对于价值超过50,000瑞士法郎的中等规模商业交易，瑞士银行可能要求在SWIFT字段70中提供完整的说明内容，包括合同发票号码、相关服务内容及商业目的；发票必须根据瑞士增值税法规开具，而关于许可费和特许权使用费的瑞士预扣税（最高为4.4%或按条约规定降低的税率）则必须向瑞士联邦税务局缴纳，之后才能退还给外国服务提供商。对于在瑞士境外的高价值基础设施采购项目，可以使用文档式商业信用证（UCP 600）；但由于AI API服务的数字化特性，通常的做法是利用银行的电子银行出口收款功能实现不可撤销的支付承诺，同时结合SWIFT MT950余额报告来进行流动性预测。使用USDC或其他稳定币进行跨境支付是不被允许的；此类支付必须在离开瑞士银行体系之前，通过FINMA监管的加密货币经纪商转换为瑞士法郎或美元。在ISDA主协议或瑞士银行场外衍生品条款下，以瑞士法郎、美元、欧元及其他可自由兑换货币为基础的普通即期外汇远期交易通过Eurex清算的瑞士法郎交易所交易期货和期权，用于管理已上市的远期头寸由获得瑞士金融市场监管局（FINMA）许可的银行直接发行的外汇看涨和看跌期权，旨在为以美元计价的API许可收入流提供不对称保护跨境货币利率互换（若引入债务融资）以对冲瑞士法郎与美元之间的利息支付不匹配非交割远期合约（NDFs）虽属于合法交易方式，但仅适用于使用受限货币进行交易的交易方；瑞士法郎本身是可以完全交割的，因此无需使用NDFs，通常也不为以瑞士法郎进行的交易提供此类合约。外汇掉期用于管理外币应收账款与瑞士法郎运营成本之间的短期流动性错配

电商与网关结算适配度: 可行性评级：中等。根据瑞士银行法、金融服务法（FinSA）以及金融机构法（FinIA），境外电子货币机构（EMI）或数字支付银行（如Stripe、Airwallex或Revolut）若要在瑞士股份公司（Swiss AG）中设立存款账户或支付账户，必须取得瑞士金融市场监管局（FINMA）的银行或金融科技牌照，或在瑞士设立分支机构。瑞士居民的AI大语言模型（LLM）API平台可将境外EMI仅作为境外信用卡和加密货币结算的收款中介，但前提是该EMI在合同中被明确豁免作为受瑞士监管的支付中介，且主要的账务结算账户须保留在瑞士FINMA持牌银行内。加密货币稳定币（如USDC）的使用仅在通过瑞士FINMA持牌的加密货币保管机构或受瑞士监管的证券公司进行路由时才可行，以规避未经许可第三方带来的风险。
